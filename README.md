# Corrected ZD410 Portal + Local Bridge
Label is 56 x 50.8 mm at 203 dpi. Product name wraps up to two lines with automatic font reduction. Barcode is centered with safe margins. Production date is mandatory. Validity date is optional when **Remove validity date from label** is selected.

Deploy as Render Web Service. Add `BRIDGE_TOKEN` in Render Environment. On printer PC run `local_bridge/install.bat`, edit `config.json`, and run `start_bridge.bat`.
